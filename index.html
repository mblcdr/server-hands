Unlock your homelab from your phone

Your server boots with its encrypted drives locked. Open the app, use your fingerprint, and the drives unlock, the mergerfs pool comes back and your containers start. LAN only: no cloud, no relay, no account.

Install Read the docs

How it works

1. Boot

The server starts with its LUKS drives locked and publishes an unlock request.

2. Open the app

It verifies the server's pinned identity and shows which drives are waiting.

3. Fingerprint

A biometric releases the passphrases, sealed to a one-time key held only in server memory.

4. Back to normal

Drives unlock and mount, the mergerfs pool refreshes and your scripts start the containers.

End-to-end encrypted

HPKE to a per-request ephemeral key on top of pinned TLS 1.3. Recorded traffic or a stolen disk reveals nothing.

Biometric vault

Passphrases sit in an Android Keystore vault that needs a fresh strong biometric for every use.

No impersonation

Pairing is done once over a QR from your SSH console. A changed server key is a hard failure.

Post-unlock scripts

Run scripts automatically after unlock, or start them from the app.

OpenMediaVault aware

Mounts through your existing fstab entries and refreshes the mergerfs pool.

Tiny and sandboxed

A small native systemd service. Revoke a lost phone with one command.

Install on the server

Signed apt repository for Debian 13 / OpenMediaVault 8, amd64. Current version: 0.7.0.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://mblcdr.github.io/server-hands/server-hands.gpg | sudo tee /etc/apt/keyrings/server-hands.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/server-hands.gpg] https://mblcdr.github.io/server-hands/ ./" | sudo tee /etc/apt/sources.list.d/server-hands.list
sudo apt update && sudo apt install server-hands

The service is not enabled automatically. Continue with the setup guide.

Verify the signing key before trusting it. Its fingerprint is 8A6B7750C817E5BFCEAE8B34023D040E2ACC8026:

gpg --show-keys --with-fingerprint /etc/apt/keyrings/server-hands.gpg

The Android app (APK) is on the GitHub Releases page.
